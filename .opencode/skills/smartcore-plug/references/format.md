# SmartCore Plug .ctcs 格式规范

从 DataGenrator.exe（.NET 工具）输出的 SmartCore_plug.ctcs 文件逆向分析得出，并经字节级核对验证。

## 整体结构

```
文件 = [数据项区: 1956 字节] + [零填充: 64 字节] = 2020 字节
```

## 数据项区

按 `Data` 工作表行顺序序列化：

| 列 | 含义 | 示例 |
|---|---|---|
| A (ID_INFO) | 字段名，不序列化 | `ID_ASW_PLUG_VERSION` |
| B (size) | 字节数，正整数才序列化 | `2.0` → 2 |
| C (Value) | 值，大端整数 | `0xee01` 或 `45.0` |

序列化规则：
- 每行 B 列有正整数 size 的字段，将 C 列值按大端（big-endian）写入 size 字节。
- C 列为 `0x...` 字符串时按十六进制解析；为数字时取整（四舍五入）。
- 跳过：表头行（`ID_INFO`）、空行、B 列无 size 的行（如 `#INFO HEAD` 标题行）。

### 数据项区末尾两行

| 行 | 字段 | size | 值 | 序列化字节 |
|---|---|---|---|---|
| 倒数第 2 | `ID_CRC_DATA` | 2 | `0xee8f` | `ee 8f` |
| 倒数第 1 | `CRC_DATA` | 4 | `0` | `00 00 00 00`（占位，生成后覆写） |

## CRC-32 算法

- 多项式：`0x04C11DB7`（标准 CRC-32/MPEG-2）
- 初始值：`0x00000000`
- 输入反射：否
- 输出反射：否
- 最终异或：`0x00000000`
- 覆盖范围：数据项区前 1952 字节（即除最后 4 字节 CRC_DATA 占位之外的全部字节）
- 结果写入：最后 4 字节，大端

参考样本 CRC = `0xa6805464`。

## 零填充

数据项区（1956 字节）之后追加 64 字节 `0x00`，总文件大小为 2020 字节。

## 验证边界

- 本规范基于单个参考样本（SmartCore_plug.xls → SmartCore_plug.ctcs）逆向得出。
- 若 xls 模板结构变化（行数增减、size 变更），数据项区大小会相应变化，但 64 字节零填充与 CRC 规则保持不变。
- 无第二个样本时，64 字节零填充为观察到的固定尾部，未做独立验证。
